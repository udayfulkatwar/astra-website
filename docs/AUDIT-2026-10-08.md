## What the site is

One Vite + React + TypeScript page. There is no client-side router. Navigation is in-page anchors. GitHub Actions builds `main` and publishes it to GitHub Pages. `public/CNAME` is `astragrp.net`.

Stack, from `package.json`: React 19, Vite 8, TypeScript 6, Three.js, React Three Fiber, GSAP, Lenis, Framer Motion. Node 22. `npm ci` reported 0 vulnerabilities.
