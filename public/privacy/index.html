Privacy

ASTRA is an independent startup project, not yet formally incorporated. This page describes the public website at astragrp.net. It is under active development. Contact founder@astragrp.net.

What this site does

  • It does not run analytics and does not set cookies.
  • It does not use browser storage. There is no account and no form that posts to a server.
  • Type is self-hosted with the page (Archivo and JetBrains Mono). The site does not request a font service such as Google Fonts.
  • Images and the product video are files on this same site, under /media/. There is no third-party video host.
  • “Launch ASTRA Demo” is a link you choose to open. It goes to a page on claude.ai. That destination is not operated by this project. ASTRA is an independent project and is not affiliated with or endorsed by Anthropic. Opening the link does not send this site a copy of what you do there.
  • “Request access” is a mailto link to founder@astragrp.net. It opens your own email program. This site receives a message only if you send one.
  • “Copy address” writes founder@astragrp.net to your device clipboard when you press the button. That text is not uploaded.

Hosting

The files are static and are served by GitHub Pages. A host of that kind can keep ordinary connection logs. This project does not run a separate analytics service, and this page does not state a log-retention period.
